## Overview

<!-- WIP -->
- Complex bashing provides a way to solve geometry problems purely using the complex plane and numbers.

## Key Ideas

<!-- WIP -->
- $z=re^{i\theta}$ with $r=|z|$ and argument $\theta$.
- $n$th roots of unity satisfy $z^n=1$ and are evenly spaced on the unit circle.
- Multiplication rotates and scales points in the plane.

## Core Concepts

<!-- Add some reference to previous modules -->
(note: for the below we will use symbols used from the previous modules in complex numbers. If not sure, consult the previous modules.)

### Perpendicular Lines

Let $A, B, C, D$ be pairwise distinct points. Then $\overline{AB} \perp \overline{CD}$ if and only if $\frac{d-c}{b-a} \in i\Re$; i.e.
$$\frac{d-c}{b-a}+\overline{\frac{d-c}{b-a}}=0$$

### Collinear Points

Let $A, B, C$ be pairwise distinct points. Then $A, B, C$ are collinear if and only if $\frac{c-a}{c-b} \in \Re$; i.e.

$$\frac{c-a}{c-b} = \overline{\frac{c-a}{c-b}}$$

### Concyclic Points

Let $A, B, C, D$ be pairwise distinct points. Then $A, B, C, D$ are concyclic if and only if

$$\frac{c-a}{c-b} : \frac{d-a}{d-b} \in \Re$$

### Reflection across line

Let $W$ be the reflection of Z across $\overline{AB}$. Then,

$$w=\frac{(a-b)\overline{z} + \overline{a} b-a\overline{b}}{\overline{a} \overline{b}}$$

## Worked Example

Compute $(1+i)^4$.

Since $1+i=\sqrt{2}e^{i\pi/4}$, we have
$(1+i)^4=(\sqrt{2})^4 e^{i\pi}=4(-1)=-4$.

## More Examples

### Example 1: Roots of Unity

Find all solutions to $z^3=1$.

$z=e^{2\pi i k/3}$ for $k=0,1,2$.

### Example 2: Modulus

If $z=3-4i$, compute $|z|$.

$5$.

### Example 3: Rotation

If $z$ is multiplied by $e^{i\pi/3}$, what happens geometrically?

It rotates by $60^\circ$ and keeps the same magnitude.
